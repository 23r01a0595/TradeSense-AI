# TradeSense AI

An AI-powered stock trading and investment assistant built with React, Spring Boot, PostgreSQL, and Gemini AI.

## Tech Stack

- React
- Spring Boot
- PostgreSQL
- Spring Security
- JWT
- Gemini AI

## Features

- User Authentication
- Portfolio Management
- Watchlist
- Buy/Sell Simulation
- AI Investment Assistant
- Live Stock Market Data
- AI Portfolio Analysis
